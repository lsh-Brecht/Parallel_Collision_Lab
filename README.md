# Parallel Collision Lab

A 3D real-time physics simulation and parallel computing lab built with C++ and DirectX 11.

## Directory

```
ParallelCollisionLab/
├── Core/          # Math library and physics simulation primitives
├── Collision/     # Collision detection algorithms (Strategy Pattern)
├── Renderer/      # DirectX 11 rendering pipeline and DirectWrite HUD
└── Window/        # Win32 window management and input handling
```
